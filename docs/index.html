03PRIVACY & PERMISSIONS

CLEAR ABOUT WHAT HAPPENS

Your reading stays
yours to return to.

Gitamrta is designed to do one job: fetch and display the verse you ask for. The current extension source keeps its permissions narrow and its saved preferences on your device.

✓

Local preferencesChrome local storage remembers your theme and last chapter/verse reference.

✓

One scripture hostNetwork requests go to the Vedic Scriptures API to retrieve the selected verse.

✓

No analytics in the current sourceThe current project source contains no analytics or advertising code.

✓

Clipboard on requestGitamrta writes verse text only when you press Copy; it does not read clipboard contents.

The API receives the requested chapter/verse path and ordinary connection metadata. Gitamrta needs an internet connection and does not currently provide an offline verse library. Review the permissions and full source before installing.

06QUESTIONS, ANSWERED

BEFORE YOU BEGIN

A few things
worth knowing.

Does Gitamrta work offline?+

No. It fetches the selected verse from the external Vedic Scriptures API, so an internet connection is required. The extension remembers your last reference, but it does not store an offline verse library.

How do I find a particular shloka?+

Enter the chapter and verse separated by a slash. For example, 2/47 opens Chapter 2, Verse 47. The extension validates the reference against its chapter verse-count list.

Why might a translation or commentary be missing?+

The API may not provide that field for the selected verse, or it may not include an entry from one of the authors supported by the current extension build. Gitamrta shows an unavailable message rather than inventing content.

What is saved on my device?+

The current extension stores your selected theme and last viewed chapter/verse in Chrome local extension storage. The verse is fetched again when you open it.

Is Gitamrta open source?+

It is source-available under a proprietary license, not an open-source license. Read the complete license terms before using the source or an official release.
