# Design credits and third-party references

## Supplied design reference

The Gitamrta interface adapts the monochrome visual system described in the project owner's supplied `design.md`. That document identifies the design reference as **Votrixain**. No separate license text for the Votrixain reference was included with the supplied design document; its ownership and any applicable reuse terms should be confirmed by the project owner before broader redistribution or reuse.

## Attributed design inspiration

The supplied design reference records that its interface refinements were guided by **Unslop** by Damir Sokolovsky, licensed under **Creative Commons Attribution 4.0 International (CC BY 4.0)**.

- Author: Damir Sokolovsky — https://x.com/heydamir

Gitamrta's visual adaptation uses the restrained monochrome palette, semantic light/dark tokens, spacing and geometry, native typography, clear hierarchy, focus states, and reduced-motion guidance described in the supplied design material.

Gitamrta requests scripture data from the Vedic Scriptures API endpoint at `https://vedicscriptures.github.io/slok/{chapter}/{verse}`. The service is external to this repository. Its own terms, attribution requirements, content rights, and privacy practices are not defined by Gitamrta's proprietary license and should be reviewed separately by the project owner.
